プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-10-12

1. 対象 / Scope

このポリシーは、個人用ツール「Life Dashboard」（以下「本ツール」）に適用されます。本ツールは開発者本人のみが利用し、一般には提供していません。

This policy applies to "Life Dashboard", a personal tool used only by its developer. It is not offered to the public.

2. 取得する情報 / Data accessed

本ツールは、Google アカウントで許可を得たうえで、Google カレンダーのカレンダー一覧と予定（タイトル、日時、場所）を読み込みます。また、利用者の操作に応じて予定を追加します。

With the user's permission, the tool reads the list of calendars and events (title, date and time, location) from Google Calendar, and creates events when the user asks it to.

3. 利用目的 / How data is used

取得した情報は、利用者自身のPC上のダッシュボードに予定を表示する目的にのみ使用します。

The data is used only to display the user's schedule on a dashboard running on the user's own computer.

4. 保存と共有 / Storage and sharing

予定の情報と認証トークンは、利用者自身のPC内にのみ保存されます。第三者への提供、販売、広告への利用、外部サーバーへの送信は行いません。

Event data and authentication tokens are stored only on the user's own computer. The data is never sold, shared with third parties, used for advertising, or sent to any external server.

5. Google API サービスのユーザーデータに関するポリシー / Google API Services User Data Policy

本ツールによる Google API から取得した情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

Life Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. アクセスの取り消し / Revoking access

許可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます。

Access can be revoked at any time from Third-party apps & services in the Google Account settings.
